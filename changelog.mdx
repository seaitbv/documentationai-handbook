## How to Update

Follow these steps to upgrade your Sea-it devices safely.

<Steps>
  <Step title="Backup Configuration" icon="database">
    Export your current settings.

````json
{
  "deviceId": "sea-it-12345",
  "geofence": {
    "enabled": true,
    "radius": 100
  }
}
````
  </Step>
  <Step title="Download Firmware" icon="download">
    Visit the [downloads page](https://www.stas.be/en-gb/downloads) and select the latest version matching your hardware.
  </Step>
  <Step title="Apply Update" icon="upload">
    Use the Sea-it app or web dashboard to flash the firmware.
  </Step>
</Steps>

<CodeGroup tabs="Dashboard,CLI">
````javascript
// Dashboard API call
const response = await fetch('https://api.sea-it.com/devices/sea-it-12345/update', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer YOUR_TOKEN' },
  body: JSON.stringify({ version: '1.2.0' })
});
````
````bash
# CLI update command
sea-it-cli update --device sea-it-12345 --version 1.2.0 --token YOUR_TOKEN
````
</CodeGroup>

## Migration Guide

<Tabs>
  <Tab title="From v1.0 to v1.1" icon="arrow-right">
    <Callout kind="tip">
      Update your auth tokens to JWT format.
    </Callout>

    Replace API key headers:

````javascript
// Old
headers: { 'X-API-Key': 'old-key' }

// New
headers: { 'Authorization': 'Bearer new-jwt-token' }
````
  </Tab>
  <Tab title="From v1.1 to v1.2" icon="settings">
    Enable new features in config:

````json
{
  "geofencing": {
    "enabled": true,
    "alerts": ["email", "sms"]
  }
}
````
  </Tab>
</Tabs>

<Expandable title="Advanced Migration Notes" default-open="false">
  For fleet operators with `>50` devices, use batch updates via the API. Contact support for enterprise scripts. Test on a single device first.
</Expandable>
