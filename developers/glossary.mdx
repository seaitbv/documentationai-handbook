## Why a glossary

The UI is Dutch first, and many identifiers, routes and design notes use Dutch words. Code comments mix Dutch and English. This table maps the terms you will see most.

## Product terms

| Term | English | Where |
|---|---|---|
| Afdeling | department; a group that grants permissions and credits | `department`, `/afdeling`, `/admin/afdelingen` |
| Beheer, beheerder | administration, admin | `/admin`, `requireAdmin()` |
| Superadmin | admin across all tenants (`app_user.super`) | `lib/permissions.ts` |
| Lead | department lead, a flag on the membership | `requireLead()`, Home → Mijn team |
| Blok | block: a preset of rule, tool and model | `lib/blocks.ts` |
| Pill | the composer control for a block | `PILLS` |
| Bron | source: something a person reads from | `GRAPH_SOURCES`, `/connectoren` |
| Connector | an MCP source linked with the person's own account | `lib/mcp.ts`, `mcp_connection` |
| Tegel | tile on the connectors page | `/connectoren` |
| Samenvatten | summarize | `/api/summarize` |
| Onderzoek | research | `research` specialist |
| Afbeelding | image | `generate_image` |
| Voorrouter | the source pick before a chat turn | `/api/sources/gather` |
| Specialist | a tool that runs its own model inside the agent | `Specialists.cs` |
| Credits | the monthly budget unit; 1 credit = EUR 0.01 | `lib/credits.ts` |

## Technical terms

| Term | Meaning |
|---|---|
| AI Gateway | the Azure API Management instance every model call goes through |
| Hosted agent | the C# orchestrator in Foundry (`agents/genius/`) |
| Middle tier | the Next.js server: routes, server actions, `lib/` |
| `data-source` part | a message part carrying fetched or attached text to the model |
| `source_ref` | what is stored instead of a source's text |
| `genius.step` | the agent's per-step accounting item |
| k threshold | the minimum group size before reporting shows a number |
| DPIA | data protection impact assessment; the running input is in `claudedocs/` |
| CAO 81 | Belgian collective agreement on monitoring electronic communications |
| Software factory | the isolate, build, prove, ship workflow |
| Worktree | a separate git checkout per change; the root checkout never changes branch |
